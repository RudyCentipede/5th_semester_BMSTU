\section{Замеры времени}

На рисунке~\ref{p1} представлены графики зависимостей времени выполнения запроса без изменения данных в БД на стороне БД и через Redis в качестве кэша.

\begin{figure}[ht]
\begin{tikzpicture}
		\begin{axis}[
			width=16cm,
			height=10cm,
			grid=both,
			xlabel={Индекс измерения},
			ylabel={Время, мс},
			legend style={at={(0.02,0.98)},anchor=north west},
			]
			
			% DB line
			\addplot table[
			col sep=comma,
			x expr=\coordindex,
			y=db_ms
			] {tables/none};
			\addlegendentry{Postgres}
			
			% Cache line
			\addplot table[
			col sep=comma,
			x expr=\coordindex,
			y=cache_ms
			] {tables/none};
			\addlegendentry{Redis}
			
		\end{axis}
\end{tikzpicture}
\caption{Зависимости времени выполнения запросов на стороне БД и через Redis. Без изменения данных в БД}
\label{p1}
\end{figure}
